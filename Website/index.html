Same measurement, two regions

Same data source, same years, same method and the same scale, so the only difference is the place.

Trends depend on the place: the same measurement can rise in one region and stay flat, or fall, in another. A trend shows what changed, not why.

Method

How we decide if a change is real

Simple, transparent statistics, the same for every region and measurement. A straight line is a simplification, and we say so.

01

Remove the seasons

Every January minus the average January, and so on. What's left shows the long-term drift without the summer–winter swing.

02

Fit a straight line

Its slope is the change per decade; slope × record length is the total change.

03

Measure the uncertainty

A 95% range for the rate and a t-test p-value. Below 0.05 we call it significant.

04

Correct for memory

A warm month is often followed by another, so 288 months hold less information than it seems. We account for that.

05

Get a second opinion

The seasonal Mann-Kendall test checks for a steady rise or fall without assuming a bell curve.
